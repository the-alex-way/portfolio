# Предобработка и исследование данных о рынке видеоигр

## Описание проекта

Проект посвящен подготовке и предобработке исторических данных о видеоиграх для дальнейшего анализа.

В рамках проекта выполнена загрузка и первичное знакомство с данными, проведена очистка данных: 
обработаны пропуски, исправлены типы данных, устранены явные и неявные дубликаты. 
Выполнена фильтрация данных за период с 2000 по 2013 год, проведена категоризация игр по оценкам 
пользователей и критиков, определены наиболее популярные игровые платформы.

## Цель проекта

Подготовить данные для последующего анализа рынка видеоигр, выполнить категоризацию игр по 
пользовательским и критическим оценкам и определить наиболее популярные игровые платформы.

## Бизнес-задачи

В рамках проекта необходимо было:

- загрузить и изучить данные о видеоиграх;
- провести предобработку данных;
- отфильтровать данные за период 2000–2013 годов;
- категоризовать игры по оценкам пользователей и критиков;
- выделить топ-7 платформ по количеству выпущенных игр.

## Используемые инструменты

- Python
- pandas
- Jupyter Notebook
- Предобработка данных
- Категоризация данных

## Этапы выполнения проекта

### Предобработка данных

Выполнена подготовка данных к анализу:

- изучена структура данных;
- проведена проверка качества данных;
- обработаны пропуски и некорректные значения;
- выполнено приведение типов данных;
- устранены явные и неявные дубликаты;
- выполнена нормализация текстовых данных.

### Фильтрация данных

Данные отфильтрованы за период с 2000 по 2013 год включительно.

### Категоризация данных

Проведена категоризация игр по оценкам пользователей и критиков с выделением трех групп: 
высокая, средняя и низкая оценка. Определены топ-7 платформ по количеству выпущенных игр за 
исследуемый период.

## Основные результаты

В ходе работы подготовлены:

- очищенный датафрейм для дальнейшего анализа;
- категориальные признаки по оценкам пользователей и критиков;
- семь наиболее популярных игровых платформ по количеству выпущенных игр.
