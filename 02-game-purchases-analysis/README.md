# Анализ внутриигровых покупок пользователей игры «Секреты Темнолесья»

## Описание проекта

Проект посвящен анализу платежного поведения пользователей онлайн-игры **«Секреты Темнолесья»**.

В рамках проекта проведен исследовательский анализ данных, изучена структура внутриигровых покупок, 
рассчитаны ключевые показатели монетизации, исследовано влияние характеристик игроков на совершение покупок, 
а также подготовлены аналитические выводы и рекомендации по повышению эффективности внутриигровой монетизации.

---

## Цель проекта

Определить особенности платежного поведения игроков, выявить факторы, влияющие на совершение внутриигровых покупок, 
и подготовить рекомендации для повышения эффективности монетизации игры.

---

## Бизнес-задачи

В рамках проекта необходимо было:

- определить долю платящих игроков;
- оценить влияние расы персонажа на вероятность совершения покупок;
- исследовать структуру и стоимость внутриигровых покупок;
- выявить аномальные транзакции;
- определить наиболее популярные игровые предметы;
- проанализировать активность игроков различных рас;
- подготовить рекомендации по развитию внутриигровой монетизации.

## Этапы выполнения проекта

### Исследовательский анализ данных

Проведен анализ:

- доли платящих пользователей;
- платежного поведения игроков;
- стоимости и структуры внутриигровых покупок;
- аномальных транзакций;
- популярности игровых предметов.

### Решение ad hoc-задачи

Исследована зависимость активности игроков от выбранной расы персонажа с использованием SQL-запросов и агрегированных показателей.

### Подготовка аналитических выводов

По результатам исследования сформулированы выводы и рекомендации для повышения эффективности внутриигровой монетизации.

---

## Практическая ценность

Результаты анализа позволяют:

- оценивать эффективность внутриигровой монетизации;
- выявлять особенности платежного поведения пользователей;
- сегментировать игроков по уровню покупательской активности;
- принимать решения по развитию игровой экономики на основе данных.
